Prepare validated task suggestions for application to tasks.md

options:
  -h, --help            show this help message and exit
  --plan-file PLAN_FILE
                        Path to the implementation plan markdown file
  --skip-human-review   [DEPRECATED] Skip needs-human-decision items (use
                        --skip-all-human instead)
  --min-priority {low,medium,high}
                        Minimum importance level to include (default: low =
                        all valid suggestions)
  --dry-run             Show what would be applied without outputting for
                        execution
  --no-batch            Disable smart batching (process each suggestion
                        separately)
  --max-batch-size MAX_BATCH_SIZE
                        Maximum suggestions per batch (default: 4)
  --approve-all-low     Auto-approve all LOW importance items with needs-
                        human-decision status
  --approve-all         Auto-approve ALL needs-human-decision items (use with
                        caution, requires --yes or --force)
  --skip-all-human      Skip all needs-human-decision and validation_failed
                        items
  --approve-importance {LOW,MEDIUM,HIGH} [{LOW,MEDIUM,HIGH} ...]
                        Auto-approve needs-human-decision items at these
                        importance levels
  --claude-decide, --let-claude-decide
                        Let Claude evaluate each needs-human-decision item
                        with its own judgment (no interactive prompt), instead
                        of asking you. Equivalent to choosing 'Let Claude
                        decide' in the interactive review. Unlike --approve-
                        all / --skip-all-human, this is a per-item judgment,
                        not a blanket rule: partially-valid items are salvaged
                        (trimmed to their worthwhile core and applied) rather
                        than skipped wholesale. Does not bypass the no-
                        selection confirmation for valid items — combine with
                        --no-confirm for fully unattended runs.
  --force, -f           Force bulk approval operations (alias for --yes)
  --include-high        Allow --approve-all to include HIGH importance items
                        (otherwise blocked)
  --resume              Resume from last checkpoint, skipping already-
                        processed items
  --fresh               Clear previous progress and start fresh
  --batch-review-mode {individual,by-importance,summary-only}
                        How to present items for human review (default: by-
                        importance)
  --accept-stale-consolidation
                        Accept consolidated decisions even if grouped.json has
                        changed since consolidation
  --no-confirm          Skip confirmation prompt when no user selections are
                        found (for unattended operation)
  --include-low         [DEPRECATED] No longer needed, low is now default. Use
                        --min-priority to filter.
  --verbose             Enable verbose/debug output
  --output-format {json,text}
                        Output format (default: text)
  --skip                Mark the phase as skipped without applying suggestions
  --mark-completed      Mark the phase as completed (call after all batches
                        are processed)

cross-cutting options:
  --host ID             Host harness driving this run (e.g. claude-code,
                        codex, opencode). Recorded for capability resolution;
                        does not change orchestration.
  --yes, -y, --non-interactive
                        Run unattended: never prompt, resolve every gate from
                        config and flags. Confirms bulk approval operations.
  --interactive, -i     Force interactive model selection (ignores YAML
                        defaults)
  --detach              Run the phase in a self-daemonized process (fan-out
                        modes only) and return immediately with its log path
                        and a status command to poll. Implies --yes. Never
                        combine with a host's own background primitive.
  --if-not-running      With --detach: if a run for this phase is already in
                        flight, print its run_id/log/status command and exit 0
                        instead of failing.
  --max-detached N      Ceiling on concurrent detached runs for this project
                        (default 4, or $MULTI_LLM_MAX_DETACHED).
  --exec-subagents      Reserved: run materialized subagent prompts through
                        the provider executor (accepted and recorded; not yet
                        implemented).

This orchestrator outputs a JSON list of task suggestions to apply.
The actual application is handled by Claude Code using Task subagents.

Example:
  uv run --project "${CLAUDE_SKILL_DIR}" -- python "${CLAUDE_SKILL_DIR}/apply_task_suggestions_orchestrator.py" --plan-file plans/my-plan.md

Bulk Approval Examples:
  # Auto-approve all LOW importance items
  uv run --project "${CLAUDE_SKILL_DIR}" -- python "${CLAUDE_SKILL_DIR}/apply_task_suggestions_orchestrator.py" --plan-file plans/my-plan.md --approve-all-low

  # Skip all items requiring human review
  uv run --project "${CLAUDE_SKILL_DIR}" -- python "${CLAUDE_SKILL_DIR}/apply_task_suggestions_orchestrator.py" --plan-file plans/my-plan.md --skip-all-human
